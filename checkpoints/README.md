# Checkpoints

The verified projection heads and ICIR descriptor table are published with the
[`v0.1.0` GitHub release](https://github.com/aminalmasi/instance-based-composed-image-retrieval/releases/tag/v0.1.0).
Their SHA-256 checksums and training configurations are recorded in
[`release_manifest.json`](release_manifest.json). Large pretrained backbone weights are not
redistributed; configuration files reference their original model repositories.
